# Press Machine vNext TEST

Candidate implementation for the current DEV-12 Revision 3 contract.

Processing order:

`Pre Saturation → Saturation Comp → Comp Skin Protect → Hue Pattern → Hue Bias / Luma Split → post-Hue Density analysis → Density / Density Chroma → Look Skin Protect → Final Shadow Desaturation`

This adapter has a new plugin identity (`com.46slv.PressMachine.vnext.test`) and does not migrate or replace Press Machine v2.0 state.

## Shared source

The canonical pixel math is generated by `../vnext/regenerate.py` from the retained common numerical helpers plus the versioned vNext pipeline. The DCTL candidate and OFX CPU/CUDA adapters use the same generated `PixelCore.hpp`.

## Windows build

Use the target Resolve 21.1 official OpenFX SDK, Visual Studio x64, and Resolve-bundled NVRTC.

```powershell
cd adapters/ofx_vnext
.\build.ps1 -Clean
```

Bundle and module use the same `PressMachineVNext` stem.

## Evidence boundary

Cloud CI compiles and runs the shared CPU core plus the independent geometry/scalar reference. CUDA/NVRTC, actual OFX SDK build, Resolve load/UI/persistence, real footage and 4K acceptance require the target Windows Resolve host and are separate evidence. Do not transfer v2.0 Host receipts to this candidate.

After a successful Windows build, and only when no Resolve render/playback owns the test GPU, run:

```powershell
python tests\verify_cuda_adapter.py
```

This exercises the actual vNext `CudaRunner` path in an independent NVIDIA context, including pitch/ROI, premultiplied alpha, default-stream completion and non-null stream behavior, and compares the output to the exact shared CPU core.
